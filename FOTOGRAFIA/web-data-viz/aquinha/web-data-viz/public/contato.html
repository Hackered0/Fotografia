Como podemos ajudar?

Separamos algumas respostas para as dúvidas mais comuns. Caso não encontre o que procura, nossa equipe estará pronta para ajudar pelos canais de contato abaixo.

Preciso criar uma conta para acessar o LYRIS?

Não. Apenas o quiz e a dashboard exigem cadastro.

O quiz pode ser realizado novamente?

Não. Cada usuário pode responder apenas uma vez.

Como descubro meu estilo fotográfico?

Após concluir o quiz, o resultado será exibido na dashboard.

O conteúdo do site é gratuito?

Sim. Todo o conteúdo educativo do LYRIS é gratuito.

Posso sugerir novos conteúdos?

Sim. Ficaremos felizes em receber sugestões e ideias.
